ABOUT SECURESCAN

Intelligent Network Security Assessment

Understanding the problem, need, working, technologies and security assessment process behind the SecureScan project.

01

What is SecureScan?

SecureScan is a Computer Science project developed as a web-based network security assessment system. It combines port scanning, service detection, vulnerability analysis and risk assessment into a single platform.

The system allows an authorized user to enter an IP address or domain and select a port range for assessment. The system then processes the target and presents the security findings through a web dashboard.

02

Why was this project needed?

A networked system can expose multiple services through open ports. Knowing that a port is open is useful, but it does not by itself explain what software is running or whether that software has known vulnerabilities.

Because of this, a security assessment needs multiple stages. SecureScan connects these stages so that port discovery can be followed by service identification, vulnerability analysis and risk assessment.

03

Problem Statement

Traditional basic port scanning provides information about accessible ports, but the findings can require additional tools and analysis to understand the associated services and known software vulnerabilities.

The project addresses this by creating one integrated workflow that moves from network visibility toward vulnerability information and an overall security assessment.

04

Project Objectives

Port Scanning

Discover open ports within the selected port range of an authorized target.

Service Detection

Identify services and available product and version information.

Vulnerability Analysis

Search known CVE records using detected software information.

Risk Assessment

Analyse CVSS scores and severity information to determine the overall assessment.

Result Presentation

Present findings, risk information and recommendations through a web dashboard.

Data Storage

Store scan, port and vulnerability information for later viewing and analysis.

05

How Does the System Work?

SecureScan follows a step-by-step security assessment workflow. Each stage produces information that is used by the next stage.

01 Target Input

User enters an authorized IP address or domain and a port range.

↓
02 Port Scanning

Python scans the selected ports and identifies accessible ports.

↓
03 Service Detection

Nmap performs service and version detection on discovered ports.

↓
04 CVE Analysis

Detected software information is used to search the NVD vulnerability database.

↓
05 Risk Assessment

CVSS scores and severity information are analysed to determine risk.

↓
06 Database

Scan findings are stored in the SQLite database.

↓
07 Security Report

The final findings are displayed through the results dashboard.

06

07

Main Modules

01 — Port Scanner

Uses Python socket-based scanning to check the selected port range.

02 — Service Detection

Uses Nmap service and version detection to identify software information.

03 — CVE Analysis

Searches the NVD API for known vulnerabilities related to detected software.

04 — Risk Assessment

Analyses CVSS scores and severity to generate an overall risk classification.

05 — Database

Stores scans, ports and vulnerability findings using SQLite.

06 — Web Dashboard

Provides scan progress, results and security recommendations.

08

Database Structure

SecureScan uses three main database tables to organize scan information.

scans

Stores the target, scan date, number of open ports, CVE count, highest CVSS and overall risk.

ports

Stores port number, service, product and version information.

vulnerabilities

Stores port number, CVE ID, CVSS score, severity and vulnerability description.

09

Risk Assessment

The system uses the highest available CVSS score among the detected vulnerabilities to determine the overall risk category.

9.0 – 10.0 CRITICAL
7.0 – 8.9 HIGH
4.0 – 6.9 MEDIUM
Above 0 – 3.9 LOW

When the system cannot perform a meaningful vulnerability assessment because the required product or version information is unavailable, it can report the result as NOT ASSESSED.

10

What Does the User Get?

After the scan is completed, the results page combines the major findings into a single security assessment.

Scanned Target IP address or domain assessed
Open Ports Accessible ports and detected services
Vulnerability Findings CVE IDs, CVSS scores and severity
Highest CVSS Highest detected vulnerability score
Overall Risk Final assessment classification
Security Recommendations Suggested actions based on findings
11

How Can It Help?

SecureScan provides a structured way to understand the security information collected from an authorized network target.

Instead of displaying only open ports, the system connects network visibility with service information, known vulnerability records and risk information.

This makes the project useful as an educational demonstration of how different cybersecurity concepts can be combined into one practical application.

12

Limitations

The system is intended for authorized security assessment and educational use.

CVE matching depends on the accuracy of the detected product and version information.

Unknown product or version information can prevent reliable vulnerability matching.

Vulnerability results depend on the information available from the vulnerability database.

13

Future Scope

Improve service and version identification for more accurate vulnerability matching.

Add more detailed remediation guidance for individual vulnerabilities.

Add downloadable security reports.

Add historical scan comparison and monitoring features.

Improve alerting and automated security monitoring capabilities.
